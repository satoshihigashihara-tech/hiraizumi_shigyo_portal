## 画面素材の扱い

`01-public-home.png`と`02-public-calendar.png`は、2026年9月13日に公開本番URLから取得した画面です。公開画面だけを保存し、実在利用者の情報は含みません。

認証が必要な画面は、実アカウント、JWT、Cookie、環境変数、Storageの署名URLを資料へ持ち込まないため、`STATIC FALLBACK`と明記した静的再現を使います。静的再現を本番スクリーンショットとは説明しません。

## 説明上の境界

- 自主制作の試作版であり、平泉町公式サービスではありません。
- mainへ統合済みのコードと、本番配備・実環境受入が完了した機能を分けて説明します。
- A9〜A12のSQL037〜040は本番へ適用・保存・検証済みです。A12の総合受入は必須CIをすべて通過してmainへ統合済みです。
