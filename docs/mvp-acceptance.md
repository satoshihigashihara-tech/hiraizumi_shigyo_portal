## 業務シナリオ

### A. キャンプ利用

- [ ] 職員がキャンプと対象メールを登録できる
- [ ] 対象外メールはキャンプ申請へ進めない
- [ ] 対象者が下書き保存、確認、提出を完了できる
- [ ] 必要な場合だけ保護者同意書を添付・差し替え・閲覧できる
- [ ] 職員が審査開始、修正依頼、再提出、部屋割り、許可を処理できる
- [ ] 料金、納付期限、未納／納付済みを確認・更新できる
- [ ] 入居、退去を処理し、早期退去後も元の期間と料金が残る

### B. 地域活動の個人利用

- [ ] 公開カレンダーには「申請可能／利用不可／受付開始前」だけが表示される
- [ ] 個人利用者が日程選択、下書き、提出、修正、再提出を完了できる
- [ ] 職員が審査、部屋割り、許可、不許可を処理できる
- [ ] 本人の取消申請中は枠を維持し、職員確定後だけ解放する
- [ ] 許可済み申請から連続した延泊申請を別申請として作成できる
- [ ] 納付、入居、退去を処理できる

### C. 地域活動の団体利用

- [ ] 代表者が2〜15人の団体と日程を作成し、団体専有枠を確保できる
- [ ] 招待リンク／コードはログイン後だけ内容を表示する
- [ ] 参加者がそれぞれ自分の情報と同意書だけを保存・提出できる
- [ ] 代表者から他参加者の住所・電話・緊急連絡先・同意書が見えない
- [ ] 全員提出後だけ団体が審査中へ進む
- [ ] 職員が目的確認、参加者審査、部屋別人数、団体許可を処理できる
- [ ] 参加者削除・交代、団体取消、許可後減員を処理できる
- [ ] 提出・修正期限切れで団体、参加者、枠、履歴が一貫して終了する
- [ ] 全宿泊者の退去後に団体が終了する

## 計算・競合・境界

- [ ] 1泊2日が600円
- [ ] 8月15日〜9月15日が9,600円
- [ ] 8月1日〜8月31日が9,000円
- [ ] 同月の別申請に月上限を別々に適用する
- [ ] 部屋定員と施設全体15人を超えない
- [ ] 下書きは枠を取らない
- [ ] 個人は15人まで重複でき、団体は期間を排他的に確保する
- [ ] 同時送信でも定員超過・団体との重複が起きない
- [ ] 期限の境界は日本時間で判定される

## 権限・個人情報

- [ ] 未ログイン画面に氏名、団体名、状態、内部理由が出ない
- [ ] 一般利用者が職員画面・職員RPCへ到達できない
- [ ] 他人の申請IDをURLへ入れても内容を取得できない
- [ ] 同意書は本人と職員だけが取得でき、短時間URLが失効する
- [ ] 職員メモと内部監査が本人・代表者へ出ない
- [ ] 入力エラーへSQL文、UUID、秘密値が表示されない
- [ ] アカウント初期化中・停止中には平易な案内と町への連絡方法が出る

- [ ] キーボードだけで操作でき、入力項目にラベルがある
- [ ] 状態や利用可否を色だけで区別しない
- [ ] エラー時に入力が保持され、該当項目へ理由が出る
